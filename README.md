# Buck M Harris - TeacherTime

This is a very simple project, but a project none the less. I was asked by a teacher in Seminole County, Florida to build
a simple application that would help students better understand time on an analog clock. So that is what I set out to build.
I built the foundation with the settings page then I employed Claude to build the clock interface. It was a quick project, but
I am still proud of it. Thank you for taking a look.
